# Експеримент: частинки у Web Worker

Воркер рахує частинки і повертає буфер з координатами (transferable, без копіювання).
Головному потоку легше не стало, бо малювання все одно на ньому. Тому в гру не взяв, цифри в головному README.

Спробувати: у `client/src/game.ts` замість `new ParticlePool(800)` поставити `new ParticlesInWorker()` і малювати через `particles.draw(ctx, frameDt)`.
